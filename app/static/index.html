🔍 About AgentLens

AgentLens is an LLM-powered multi-agent communication defect detection and analysis platform. It helps AI engineers identify systematic breakdowns in agent collaboration, hallucinations, contradictions, and protocol failures.


🏗️ Methodology

Detection uses a two-stage hybrid pipeline:

  1. Rule-Based Detector — TF-IDF cosine similarity for loop detection, regex-based unanswered request tracking, structural protocol checks.
  2. LLM Judge — Sliding window analysis via Claude claude-3-5-sonnet, strict JSON schema enforcement, concurrent window processing with semaphore control.
  3. Merge & Deduplicate — Matched findings become hybrid defects with boosted confidence; unique findings from each source are kept.

🧬 Defect Taxonomy

${[ ['AMBIGUOUS_INSTRUCTION','high','Vague or underspecified request lacking explicit requirements.'], ['INCOMPLETE_INFORMATION','medium','Key parameters, context, or code missing from a message.'], ['CONTRADICTION','critical','Message conflicts directly with earlier verified context.'], ['INFORMATION_LOSS','high','Key info from earlier steps dropped by a later agent.'], ['MISINTERPRETATION','high','Agent misreads or misunderstands another agent\'s output.'], ['REDUNDANT_LOOP','high','Repeated ping-pong with no meaningful task progress.'], ['IGNORED_REQUEST','high','A request or question that never gets answered.'], ['ROLE_VIOLATION','high','Agent acts outside its assigned system role.'], ['HALLUCINATED_CLAIM','high','Agent states unsupported facts as established truth.'], ['PROTOCOL_VIOLATION','high','Wrong format, unknown recipient, or broken structure.'], ].map(([name, sev, desc]) => `
${name.replace(/_/g,' ')} ${sev.toUpperCase()}
${desc}
`).join('')}
⚡ Health Score Formula
Base Score: 100
Defect Penalty: raw = Σ weight(severity) × defect_count
  weight: critical=18 | high=10 | medium=5 | low=2
  defect_density = defect_count / message_count
  volume_factor = 0.6 + 0.4 × min(1, density)
  scaled_penalty = min(85, raw × volume_factor)
Network Penalty: 5 per isolated agent (max 10) + 5 if cycles ≥ 2
Final Score: max(0, min(100, round(100 − scaled_penalty − network_penalty)))
Grade: A≥90 | B≥80 | C≥70 | D≥60 | F<60
